# RÉFÉRENCE — GUIDE HTML INTERACTIF — SÉANCE 19

**Version :** V1  
**Statut :** À VALIDER
**Collecte réseau :** aucune

## Emplacement

```text
MODULE-05/SORTIES/GUIDE-SUIVI-SEANCE-19-HTML-V1-A-VALIDER/index.html
```

## Fonction

Le guide accompagne un candidat depuis le cadrage de son activité jusqu’à une PWA locale minimale prête pour validation humaine. Il ne génère pas automatiquement l’application : il structure les informations de départ, personnalise les prompts, mémorise localement la progression et prépare la preuve.

## Parcours intégré

1. définir activité, public, besoin et usage hors connexion ;
2. confirmer la sauvegarde de la V1 et la création de la V2 ;
3. inventorier les contenus publics autorisés ;
4. exécuter les prompts 19-A à 19-F ;
5. construire et contrôler le JSON et `fetch()` ;
6. tester succès, vide, 404, schéma invalide et lien dangereux ;
7. intégrer manifeste, icônes, page hors connexion et service worker ;
8. contrôler cache, clavier, responsive et fonctionnement hors connexion ;
9. produire la preuve 19 ;
10. demander une validation humaine avant publication.

## Fonctions locales

- sauvegarde automatique dans `localStorage` ;
- personnalisation et copie des six prompts ;
- progression par contrôles ;
- génération locale d’une synthèse de preuve ;
- impression ou export PDF par le navigateur ;
- remise à zéro confirmée ;
- navigation adaptée au mobile.

## Limites

- aucune API connectée ;
- aucune donnée transmise ;
- aucun service worker activé dans le guide lui-même ;
- aucune publication ;
- aucune validation technique simulée ;
- les résultats de tests doivent être renseignés par le candidat.

Le guide reste au statut `V1 — À VALIDER` jusqu’à la décision du pilote humain.

# Lire les sources du parcours

Les dossiers ATELIERS/S17 à S20 contiennent des instantanés locaux datés du 26 novembre 2026, avec leurs empreintes dans SYNCHRONISATION-S17-S20.json. Les liens relatifs des documents d’origine concernent leurs dépôts respectifs ; les accès utilisables dans ce dossier sont ceux de l’accueil et de la matrice.

Le cadre courant suit les ateliers effectivement disponibles : fondations en S17 ; production du pack en S18 ; JSON/HTTP/DOM en S19 ; revue lecteur et comparaison en S20. Le README S19 V2 et la fiche historique fondent le périmètre de S19, avec PWA facultative.

Le prompt maître général hérité et les anciens modèles d’assemblage sont conservés comme références historiques. Leur ancien objectif S19 ne remplace pas la matrice courante. Le pack V3 S19 reste inchangé et ne pilote pas cette synchronisation.

Le carnet transversal possède son propre format JSON ; les preuves Markdown et les fichiers assurent la continuité entre les outils. Voir le passage S19–S20 pour les limites de l’importeur S20 actuel.

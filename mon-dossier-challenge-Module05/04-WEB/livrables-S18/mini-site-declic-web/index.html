01 · COMPRENDRE

Ce qui s’affiche a une structure.

Vous voyez une page. Mais quel fichier organise son texte, choisit ses couleurs ou réagit à votre clic ?

Ce support vous permet d’observer ces trois rôles dans une page locale et de repérer le rôle du navigateur.

Un objectif à votre portée

Voir une interaction et retrouver le fichier qui la produit. Cette initiation ne promet pas de maîtriser tout le développement web.

Source : guide pédagogique fictif SRC-01.

02 · REPÉRER

Trois fichiers.
Trois responsabilités.

Le navigateur lit les fichiers et affiche le résultat. Commencez par reconnaître ce que chacun apporte.

< / >

index.html

HTML structure.

Titre, paragraphes, image et lien : HTML organise le contenu de la page.

À repérer : le titre « Déclic Web ».
{ }

css/styles.css

CSS présente.

Couleurs, disposition et lisibilité : CSS règle la présentation du contenu.

À repérer : le bleu nuit et les accents or.
JS

js/app.js

JavaScript réagit.

Un clic peut afficher ou masquer une explication en changeant l’état de la page.

À repérer : le bouton de l’essai ci-dessous.

Repères : guide SRC-01 et fiche SRC-03. Les fichiers de cette V1 sont des réalisations nouvelles à partir de ces sources.

03 · ESSAYER

Un clic.
Un changement observable.

Prédisez ce que le bouton va faire. Activez-le, puis comparez votre observation à l’explication.

  1. Ouvrir index.html.
  2. Observer le bouton et son état.
  3. Retrouver le comportement dans js/app.js.
PETIT LABORATOIRE LOCAL

Faire apparaître une explication

Que vient-il de se passer ?

HTML définit le bouton et ce texte. CSS règle leur apparence. JavaScript écoute le clic, change l’état de cette zone et actualise le libellé du bouton.

Le navigateur affiche le résultat. Activez à nouveau le bouton pour masquer cette zone.

Essayez aussi avec Tab puis Entrée ou Espace.

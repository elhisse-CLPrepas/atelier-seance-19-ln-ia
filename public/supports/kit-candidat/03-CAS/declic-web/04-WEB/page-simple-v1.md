# Contenus et liens dans une même fiche

Une fiche pour retrouver les points contenus et liens.

## Le besoin

Les points de lecture sont plus faciles à retrouver quand ils sont réunis.

## La proposition

Cette fiche réunit les points de lecture sur les contenus et les liens.

## Le bénéfice

Vous retrouvez les deux points dans une même fiche.

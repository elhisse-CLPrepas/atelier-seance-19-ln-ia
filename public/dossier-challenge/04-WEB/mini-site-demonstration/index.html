Observer un événement

Cliquez, puis décrivez ce qui change

Le bouton existe dans la structure HTML. CSS lui donne son apparence. JavaScript écoute le clic et change l’état de la zone explicative.

Événement observé : clic

  1. Le navigateur détecte l’action sur le bouton.
  2. JavaScript reçoit l’événement.
  3. La règle prévue modifie l’état de cette zone.
  4. Le texte du bouton et son état accessible sont actualisés.

Contrôle humain : l’interaction fonctionne localement, mais elle ne publie et ne transmet aucune donnée.

Ne pas confondre

Local, prêt à déployer, publié

Un projet ne devient pas public simplement parce qu’il fonctionne dans le navigateur.

  1. 01

    Projet local

    Les fichiers sont présents sur l’ordinateur et ouverts pour être testés.

    État actuel
  2. 02

    Paquet contrôlé

    Les chemins, contenus, interactions et données sensibles sont vérifiés.

    Action future
  3. 03

    Validation humaine

    Le pilote décide si le projet peut être déployé et selon quelles modalités.

    Décision obligatoire
  4. 04

    Site publié

    Les fichiers sont hébergés et l’adresse publique est contrôlée après publication.

# Sources et choix de S19

Le cadre principal est PROMPT-MAITRE-MODULE-05(4).md fourni par le formateur, version du 12 novembre 2026. Le contenu S18 et son relais réalisés dans cette conversation constituent le point de reprise.

La fiche S19 jointe et les 13 documents du pack d’été figurent sans réécriture dans docs/sources. Le ZIP Module05 contient les mêmes pièces et le démonstrateur JSON V2. Les divergences juillet/août sont expliquées dans supports/REPERES-S19-ETE-AUTOMNE.md.

La forme reprend le mini-site S18 approuvé : onze rubriques, bleu nuit et or, projection navigable, carnet, cartes et quiz. Les adresses S13 à S16 ont été fournies comme références. Leur consultation web a été indisponible lors de cette édition. La continuité repose sur les fichiers S17/S18 déjà réalisés et approuvés.

## Choix d’assemblage

La page et sa fiche sont regroupées dans 04-WEB avec un sous-dossier pieces/. Le chemin est relatif depuis page-simple-v1.html. Les exemples restent fictifs. Les observations ne sont pas remplies automatiquement.

Le laboratoire JSON est une reconstruction autonome du geste pédagogique d’été. Il teste des fichiers locaux, contrôle réponse HTTP et schéma puis crée les éléments avec textContent. Il n’inclut pas api.php ni service worker actif.
